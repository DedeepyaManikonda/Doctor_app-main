 MediBook – Doctor Appointment System

A full-stack web application that enables patients to book appointments with doctors, manage schedules, and track medical history with real-time updates and analytics.



## Features

 Patient
- Register & Login
- Browse doctors by specialty
- Book appointments (Online / Offline)
- View appointment history
- Medical history tracking

### Doctor
- Login & Dashboard
- Add / Manage availability slots
- View appointments
- Confirm appointments
- Update status:
  - ✅ Completed
  - ❌ Cancelled

- Daily summary (appointments + revenue)

### Admin
- Admin login
- View all appointments
- Slot monitoring
- Revenue analytics
